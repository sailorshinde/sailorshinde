## 🔍 QUALITY GATES & TESTING

### Before Publishing Any Content

#### For Blog Posts:
- [ ] Author byline with credentials
- [ ] Publication date visible
- [ ] 2+ external source links
- [ ] 1,200+ words (minimum)
- [ ] Clear H1 → H2 → H3 hierarchy
- [ ] 2-3 internal links minimum
- [ ] No broken links
- [ ] Schema markup (Article + Author)
- [ ] Featured image with alt text
- [ ] Mobile formatting correct
- [ ] Plagiarism check <5%

#### For Glossary Terms:
- [ ] 150-300 word definition
- [ ] Clear, non-technical language
- [ ] 1+ internal link
- [ ] Examples or context provided
- [ ] Related terms linked
- [ ] Author/source noted
- [ ] Mobile optimized

#### For Pillar Pages:
- [ ] 4,000+ words
- [ ] Table of contents with anchors
- [ ] 10+ internal links minimum
- [ ] Multiple H2 subheadings
- [ ] Visual elements (bullets, tables)
- [ ] Call-to-action button
- [ ] Author bio included
- [ ] Schema markup complete

#### For Q&A Content:
- [ ] Question naturally phrased
- [ ] Answer 200-400 words
- [ ] Direct answer in first sentence
- [ ] Examples or scenarios included
- [ ] 1+ internal link
- [ ] FAQPage schema markup
- [ ] Related questions linked
- [ ] Voice search optimized

## 📱 CONTENT TYPE TEMPLATES

### Author Byline Template
```
By [Author Name], [Job Title]
[2-3 sentence bio: Years in industry, expertise area, notable achievement]

[Optional: LinkedIn link | Twitter handle | Email]
```

**Example:**
```
By Jonathan F. Kestenbaum, Managing Director of Technology Strategy
Jonathan leads AMS's technology strategy with 15+ years in enterprise talent systems. 
Former CTO at [Company], he specializes in RPO automation and AI integration. 
Connect on LinkedIn: linkedin.com/in/kestenbaum
```

### Glossary Entry Template
```
## [Term]

[Opening sentence definition - 1-2 sentences]

[Context paragraph - 2-3 sentences explaining how it applies]

**Example:**
[Real-world scenario or usage example]

**Related Terms:**
- [Link to related term 1]
- [Link to related term 2]
- [Link to related term 3]

**Learn More:**
[Link to full article or guide about this topic]
```

### Internal Link Template
```
[Existing sentence ending...] 
Learn more in our comprehensive guide to [related topic](URL).

Or:

Our [article on [topic](URL)] covers this in detail.
```
